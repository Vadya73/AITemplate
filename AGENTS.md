# Правила кодовых агентов

- Объяснения — на русском; код, идентификаторы, комментарии и коммиты — на английском, если проект не требует иного.
  Отвечай кратко и конкретно: результат, проверка, существенные ограничения.
- Выполняй согласованную задачу до проверяемого результата; сохраняй чужие изменения и поведение вне задачи.
  Существенные неизвестные требования уточняй до зависимых изменений; рутинные обратимые решения принимай самостоятельно.
- Не подключайся к реальной или локальной БД, не выполняй запросы и миграции.
  Готовь код и файлы миграций; операции с БД выполняет пользователь.
- Не публикуй, не отправляй изменения в remote и не выполняй разрушительные операции без соответствующего запроса.
  Не переноси секреты, машинные разрешения и историю другого проекта.
- Не редактируй сгенерированные артефакты вручную: изменяй источник и запускай его генератор.
- До правок проверь состояние затронутых файлов.
  Подтверждай результат подходящей проверкой; недоступная проверка означает «не проверено», а не успех.
- На Windows предпочитай MCP/нативный инструмент при равных возможностях, группируй терминальные проверки и скрывай окна фоновых процессов.
  Не пропускай необходимую проверку ради этого предпочтения; проверяй абсолютный путь перед рекурсивным удалением/перемещением.

## Контекст по задаче

Читай только нужные материалы и применимые вложенные инструкции.
Известная небольшая правка не требует полного знакомства с проектом.

| Когда | Куда смотреть |
|---|---|
| Неизвестны команды, границы модулей, локальные исключения | [Паспорт проекта](Docs/agent-rules/PROJECT.md) |
| Нужен контекст подсистемы | [Индекс документации](Docs/INDEX.md), затем нужные секции |
| Известен русский термин, неизвестно имя в коде | [Глоссарий](Docs/_brain/glossary.md) |
| Нужна реализация | Адресный `rg`, IDE/Editor; [карта C#](Docs/_brain/index/symbols.tsv), если полезна и актуальна |
| Работа с C# / Unity | [C#](Docs/agent-rules/CSHARP.md) / [Unity](Docs/agent-rules/UNITY.md) |
| Изменён задокументированный контракт | [Правила документации](Docs/agent-rules/WORKFLOW.md), [плейбук](Docs/_brain/playbooks/document-a-mechanic.md) |
| Продолжение незавершённой задачи | [Handoff](Docs/Memory/HANDOFF.md) |
| Первичная адаптация, документация, проверка Unity | Соответствующий skill в `.agents/skills` или `.claude/skills` |

## Проверка и завершение

Из корня проекта: `python Scripts/agent.py doctor`, затем подходящая `verify fast` / `verify full`.
Команды продукта задаются в `.agent/project.json`; отсутствие настроенных проверок явно сообщается.
Для документации: `python Scripts/agent.py sync`; для диагностики актуальности без записи: `python Scripts/agent.py status`.
Дату и отпечатки сверки обновляй через `attest <документ> --reviewed` только после фактической проверки текста по коду.
В режиме анализа не записывай файлы; стандартный Stop-hook только проверяет и не исправляет их.
