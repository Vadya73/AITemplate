# Claude Code

Общие правила находятся в одном файле, чтобы Codex и Claude не расходились.

@AGENTS.md

Загружай проектные и тематические правила по маршруту из `AGENTS.md` только для текущей задачи.
Stop-hook из `.claude/settings.json` выполняет проверку без записи; режим и строгость задаются в `.agent/project.json`.
Наличие настройки не подтверждает фактическое подключение hook в установленном Claude.
