# Адаптация переносимого шаблона

Используй при первичной настройке этого шаблона в существующем проекте или повторной проверке адаптации.
Это изменение агентной инфраструктуры, не разрешение менять продуктовый код.

Установи реальные версии и точки входа по файлам проекта, существующим инструкциям и доступным инструментам.
Заполни `Docs/agent-rules/PROJECT.md`, карту продукта, архитектуру и корни `brain.yaml` только подтверждёнными фактами.
Укажи имя, тип проекта и `project.configured: true` в `.agent/project.json`, когда существенная адаптация завершена.
Добавь в `verification.fast` и `verification.full` существующие команды как массивы `argv`, с рабочим каталогом и временем ожидания.
Команды выполняются без shell; `{python}` и `{root}` подставляются инструментом.
Не копируй в проверки продуктового проекта тесты из другой игры; не запускай миграции, подключения к БД и релизные команды.

Запусти `python Scripts/agent.py doctor`, затем подходящие проверки.
Для Unity контактируй с Editor только когда это нужно текущей задаче; отсутствие соединения не подменяется догадкой по YAML.
Неизвестные требования, влияющие на результат, уточни; остальные поля оставь явно неизвестными.

После разрешённых изменений документации выполни `python Scripts/agent.py sync` и `verify fast`.
Если продуктовые проверки ещё отсутствуют, результат должен прямо содержать это ограничение; инфраструктура не подтверждает работоспособность приложения.
Подробная настройка: [SETUP](../../Docs/agent-rules/SETUP.md).
