# Проверка изменения Unity через Editor

Используй для проверки компиляции, сцены/префаба, поведения в Play Mode или визуального результата Unity-изменения.
Не устанавливай новые инструменты и пакеты только для выполнения этого skill.

Проверь [Unity-правила](../../Docs/agent-rules/UNITY.md) и реальные команды проекта, если они неизвестны.
Выбери доступный CLI или MCP и проверь, что он обращается к нужному проекту и главному Editor.
При нескольких Editor/виртуальных игроках указывай целевой проект явно.

Проверка должна соответствовать изменению: компиляция и Console для скриптов, реальный сценарий для поведения, Game view и геометрия для UI.
Не запускай полную сборку игры после каждой мелкой правки, если локальная проверка закрывает риск.
Останови Play Mode перед изменением скриптов; сохрани разрешённые изменения сцены/префаба.

Если Editor недоступен, сохрани результат независимых проверок, сообщи, что именно не проверено, и один раз уточни дальнейшую работу, если соединение нужно для задачи.
Чтение исходника не считается компиляцией, а фиктивный тест не считается проверкой Editor.
В итоговом отчёте назови реальный инструмент, целевой проект, проверенный сценарий и ограничения.
