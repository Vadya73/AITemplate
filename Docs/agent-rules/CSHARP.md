# C#

Применяется только при работе с C#.
Синтаксис и API должны соответствовать фактической версии языка и целевому runtime проекта.

## Стиль

- Типы, публичные методы и свойства — `PascalCase`; параметры и локальные переменные — `camelCase`.
- Приватные поля, включая `[SerializeField] private`, — `_leadingUnderscore`.
- Интерфейсы — `IName`; один основной тип на файл, имя файла совпадает с именем типа.
- Не размещай тело `if`, `for`, `while`, `foreach` на той же строке, что и оператор.
  Сохраняй принятый рядом стиль скобок.
- Предпочитай небольшие методы и явные зависимости, избегай глубоких иерархий и лишних абстракций.
- `/// <summary>` используй для публичного API с неочевидным контрактом, а не для каждого члена.
- Не добавляй суффиксы legacy-фреймворков и ограничения конкретного ECS без проектного правила.

```csharp
if (condition)
{
    return;
}
```

## Контракты

На каждую подписку на событие должна приходиться отписка с соответствующим временем жизни.
Не подавляй ошибки пустым `catch`; учитывай отмену и освобождение ресурсов в асинхронном коде.
Если используются стабильные числовые ID в протоколе или сохранениях, сохраняй их совместимость по [плейбуку](../_brain/playbooks/extend-protocol.md).
Наличие MessagePack, DI-контейнера или конкретного генератора не предполагается.
