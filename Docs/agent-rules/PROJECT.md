# Паспорт проекта и локальные правила

Этот файл заполняется заново для каждого проекта.
Здесь нет унаследованных версий, SDK и архитектуры исходного проекта.
Пустые значения не являются фактами и не блокируют независимую работу.

## Назначение и границы

- Название: не задано.
- Продукт и основные сценарии: не заданы.
- Платформы и окружения: не заданы.
- Состояние релиза и требования обратной совместимости: не установлены.
- Связанные репозитории, их роли и относительные пути: не заданы.

## Стек и архитектура

- Языки и версии, подтверждённые файлами проекта: не установлены.
- Движок/фреймворк и источник версии: не установлены.
- Пакеты и SDK, фактически установленные в проекте: не установлены.
- Точки входа и порядок инициализации: не установлены.
- Модули, пространства имён и границы ответственности: не установлены.
- Источники истины для данных, конфигурации и переводов: не установлены.
- DI, события, таймеры, UI и загрузка ресурсов: следовать существующим решениям после их изучения.
- Запрещённые для новых функций legacy-подсистемы: не заданы.

## Команды и проверки

Заполняй только проверенными командами, указывай рабочий каталог и необходимые переменные окружения.
Не запускай выдуманную команду сборки из примера.

| Действие | Команда / инструмент | Рабочий каталог | Статус проверки |
|---|---|---|---|
| Сборка приложения | не задано | не задано | не проверено |
| Тесты | не задано | не задано | не проверено |
| Линтер / форматирование | не задано | не задано | не проверено |
| Генерация кода | не задано | не задано | не проверено |
| Индекс документации | `python Docs/_brain/build.py` | корень проекта | проверить после переноса |
| Проверка документации без записи | `python Docs/_brain/build.py --check` | корень проекта | проверить после переноса |
| Диагностика окружения | `python Scripts/agent.py doctor` | корень проекта | проверить после переноса |
| Быстрые / полные проверки | `python Scripts/agent.py verify fast` / `verify full` | корень проекта | настроить команды продукта |

Машиночитаемый источник исполняемых команд — `.agent/project.json`; паспорт объясняет их назначение и ограничения.
Схема аргументов и коды возврата: [OPERATIONS](OPERATIONS.md).
После завершения адаптации укажи `project.name`, `project.kind` и `project.configured: true`.

## Локальные соглашения

- Именование веток, коммитов и номера задач: не задано; следовать существующей истории после изучения.
- Особые правила API, сериализации, идентификаторов и сохранений: не заданы.
- Сгенерированные файлы и команды их обновления: не заданы.
- Нужна ли отдельная авторизация на конкретный генератор: не задано; уточнить, если его побочные эффекты неясны.
- Локализация: не задана; не предполагать наличие I2, Google Sheets или конкретного языка продукта.
- Исключения из общих правил: отсутствуют.

## Настройка Second Brain

В `Docs/_brain/brain.yaml` задать заголовок, роль репозитория, домены, документы и реальные корни исходников.
Пути `symbols_index.roots` и `coverage.code[].root` считаются от `Docs/`; пути `code:` в документах — от корня проекта.
Индекс символов встроенного генератора поддерживает C#; для других языков используй `rg` или подключи отдельный индексатор.
Не добавляй глобальный корень проекта, vendor-код, `Library`, `Temp`, `Packages` и другие кэши в сканирование.
