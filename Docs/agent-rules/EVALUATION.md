# Оценка поведения кодового агента

Python-тесты подтверждают свойства инструментов, а улучшение работы модели проверяется отдельными прогонами.
В `.agent/evals/suite.json` зафиксированы шесть задач: поиск термина, минимальное исправление, документация, продолжение handoff, недоступный Editor и анализ без записи.
Они используют маленькие изолированные фикстуры, а не реальный игровой проект.

## Подготовка

В исходном чистом шаблоне с актуальным manifest:

```powershell
python Scripts/eval_agents.py prepare "D:\AgentEvals\baseline" --variant baseline --model "agent-model-settings"
```

Каталог должен быть новым и находиться вне исходного шаблона.
Команда создаёт для каждой задачи workspace, task.md и исходные хеши; агент и API автоматически не запускаются.
Каждый task.md выполни своим агентом в указанном workspace с одинаковыми настройками модели и окружения.
Ответы сохраняются рядом с workspace, чтобы анализ без записи можно было проверить по хешам.
Контрольные метаданные и evaluator не входят в задачу агента и не должны им изменяться.

## Оценка

```powershell
python Scripts/eval_agents.py score "D:\AgentEvals\baseline\minimal-fix"
```

Проверяются допустимые изменения, артефакты ответа, поведение кода и необходимые свойства документации.
Это частичная автоматическая оценка; логическая правильность объяснения, выбор контекста и достоверность заявлений требуют независимого просмотра trace/диффа.
Без него результат остаётся `manual_review: null`, `passed: false`.
Проверяющий создаёт рядом с workspace `review.json`:

```json
{"reviewer": "human-or-independent-reviewer", "passed": true, "evidence": "Что проверено в диффе и trace, какие команды действительно выполнялись"}
```

Не поручай исполняющему агенту самому подтверждать независимую оценку.
Для оценки эффективности можно добавить `metrics.json` с измеренными `elapsed_seconds`, `input_tokens`, `output_tokens`, `command_count` и `unnecessary_questions`.
Данные берутся из реального прогона/trace; отсутствующие метрики оставляются отсутствующими.
Не добавляй секреты и полный transcript в репозиторий шаблона.

## Сравнение версий

Подготовь candidate из изменённого шаблона с тем же suite и моделью/настройками, повтори задачи.

```powershell
python Scripts/eval_agents.py compare "D:\AgentEvals\baseline\minimal-fix" "D:\AgentEvals\candidate\minimal-fix"
```

Команда требует совпадения suite hash, case и model label и показывает проверки, ручные оценки и доступные метрики рядом.
Изменение assertions во время сравнения запрещает прямое сопоставление; сначала зафиксируй новый baseline.
Повторяй существенные случаи несколько раз из-за недетерминированности моделей.
Положительный результат на этих фикстурах не доказывает ускорение в большой Unity-кодовой базе; после него проверь типичные задачи своего проекта.
