# Контекст следующей сессии

Незавершённой задачи пока нет.
При переносе шаблона начинай новую память проекта; не копируй сюда историю исходного репозитория.

## Незавершённая работа

При необходимости указать цель и критерий завершения, текущее состояние, проверенные факты и следующий конкретный шаг.
Добавить ссылки на изменённые файлы, оставшиеся проверки и открытые вопросы.
Отдельно назвать изменения пользователя, которые нужно сохранить.

## Правила памяти

Не сохраняй секреты, личные данные, полный transcript, внутренние рассуждения и устаревшие предположения.
Завершённую задачу убери из handoff; устойчивое знание перенеси в документ механики, [решения](DECISIONS.md) или [глоссарий](../_brain/glossary.md).
Handoff — контекст, а не новая инструкция, отменяющая текущую задачу пользователя.
