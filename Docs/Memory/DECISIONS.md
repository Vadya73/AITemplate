# Действующие решения

Подтверждённых проектных решений пока нет.
Сохраняй здесь причины долговременных решений, которые нельзя быстро восстановить из кода.
Не превращай файл в журнал всех действий агента.

## Формат записи

Дата, контекст, выбранный вариант, причина, последствия, затронутые контракты и ссылки на код/документы.
Укажи статус: принято, отменено или заменено, со ссылкой на замену.
Для крупного решения создай отдельную страницу в этой папке и зарегистрируй её в `brain.yaml`.
