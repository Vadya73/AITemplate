# Добавить текст или язык

1. Установи используемую систему локализации и источник истины по текущему проекту.
   Не предполагай наличие I2 или Google Sheets.
2. Следуй существующему формату ключей и основному языку продукта; добавь контекст и ограничения длины для перевода.
3. Если источник переводов внешний, подготовь обменный файл в нужном формате; не редактируй сгенерированный локальный каталог вместо источника.
4. Для статического текста используй штатный компонент/биндинг локализации, для динамического — API системы с подстановками.
   У одного текстового поля должен быть один владелец значения, чтобы перевод не затирал динамический результат.
5. Если перевод может отсутствовать, обеспечь подходящий fallback; пустой ответ или возвращённый ключ не должны случайно попадать в пользовательский интерфейс.
6. Проверь подстановки, множественные формы, длину, переносы, шрифтовые fallback, RTL и переключение языка по требованиям проекта.
7. Обнови документ и пересобери индекс, если изменился контракт или процесс работы с переводами.

См. [паспорт проекта](../../agent-rules/PROJECT.md) и [документирование](document-a-mechanic.md).
