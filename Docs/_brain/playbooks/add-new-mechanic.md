# Добавить механику или подсистему

1. Открой [индекс](../../INDEX.md), соседние контракты, [ловушки](../registries/Pitfalls.md) и [паспорт проекта](../../agent-rules/PROJECT.md).
2. Определи владельца состояния, источник истины, границы модулей и критерии готовности.
   Не предполагай наличие сервера, БД, Addressables, ECS или DI-контейнера.
3. Проверь существующие решения и используй принятые точки расширения.
   Для Unity применяй [композицию](../../Guides/UNITY_COMPOSITION_GUIDE.md).
4. Уточни неизвестные требования до зависимых изменений.
5. При изменении контрактов используй [протокольный плейбук](extend-protocol.md), при работе с текстами — [плейбук локализации](add-text-or-language.md).
6. Реализуй целостный минимальный сценарий; проверь границы, повторный вызов, ошибки и совместимость.
7. Обнови описание по [плейбуку документации](document-a-mechanic.md), пересобери Second Brain.

Команды сборки и конкретные ограничения бери из текущего проекта.
Операции с БД выполняет пользователь, агент пишет файлы кода и миграций.
